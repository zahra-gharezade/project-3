# 👗 Luxury Fashion & Studio Website

A modern, elegant, and editorial fashion studio website built with HTML5 & modern CSS3.

🚀 **Live Demo:** https://zahra-gharezade.github.io/first-project/

---

### ✨ Features
- 🖤 **Modern Dark Aesthetic:** Minimalist luxury vibe with custom accent colors.
- 📐 **CSS Grid Lookbook:** Asymmetric editorial photo gallery.
- 🧭 **Smooth Navigation:** Interactive dropdown menus and hover micro-interactions.
- 📱 **Fully Responsive:** Adapts cleanly across desktop and mobile screens.

### 🛠️ Tech Stack
- **HTML5** (Semantic structure)
- **CSS3** (Flexbox, Grid, Nesting & Transitions)
- **Remix Icon** (Vector icons)
